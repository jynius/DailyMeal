# DailyMeal 앱 설명

## 📱 간단한 설명 (80자 이내)
```
매일의 식사를 기록하고 공유하세요. 사진, 장소, 평점으로 나만의 맛집 지도 완성!
```

## 📝 자세한 설명 (4000자)

```markdown
# DailyMeal - 매일의 식사 기록

당신의 소중한 식사 순간을 기록하고 공유하는 앱입니다.

## ✨ 주요 기능

### 📸 식사 사진 등록
• 갤러리에서 사진 선택 또는 카메라로 즉시 촬영
• 한 번에 여러 장의 사진 업로드 가능
• 아름다운 사진으로 맛있는 순간을 기록하세요

### ⭐ 평점 및 메모
• 1~5점 별점으로 만족도 평가
• 맛, 분위기, 서비스를 상세하게 기록
• 나중에 다시 찾아보기 쉽게 메모 작성

### 📍 장소 자동 기록
• GPS로 식사 장소 자동 저장
• 지도에서 내가 방문한 맛집 한눈에 확인
• 여행지의 맛집도 놓치지 않고 기록

### 🗺️ 지도 보기
• 내 모든 식사 장소를 지도에 표시
• 지역별로 맛집 탐방 현황 확인
• 다음 방문지 계획하기 편리

### 🔔 실시간 피드
• 친구들의 최신 맛집 추천 확인
• 실시간으로 업데이트되는 맛있는 이야기
• 새로운 맛집 발견의 즐거움

### 💬 소통 기능
• 좋아요와 댓글로 공감 표현
• 친구들과 맛집 정보 공유
• 맛집 추천 주고받기

## 🎯 이런 분께 추천합니다

• **맛집 탐방을 즐기시는 분**
  혼자만의 맛집 지도를 만들어보세요

• **식사 일기를 작성하시는 분**
  매일의 식사를 기록하고 추억을 남기세요

• **여행을 좋아하시는 분**
  여행지의 특별한 음식을 기록하세요

• **음식 사진 찍기를 좋아하시는 분**
  아름다운 음식 사진을 갤러리처럼 모아보세요

• **친구들과 맛집을 공유하고 싶으신 분**
  좋은 맛집은 함께 나눠요

## 💡 특별한 점

### 간편한 기록
복잡한 입력 없이 사진과 간단한 정보만으로 빠르게 기록할 수 있습니다.

### 자동 위치 저장
매번 주소를 입력할 필요 없이 GPS로 자동 저장됩니다.

### 깔끔한 디자인
보기 편한 인터페이스로 스트레스 없이 사용할 수 있습니다.

### 무료 서비스
모든 핵심 기능을 무료로 이용할 수 있습니다.

## 🔒 개인정보 보호

• 사용자의 데이터는 안전하게 암호화되어 저장됩니다
• 위치 정보는 사용자가 직접 공유를 선택할 수 있습니다
• 언제든지 계정과 데이터를 삭제할 수 있습니다
• 광고 없는 깨끗한 환경을 제공합니다
```
